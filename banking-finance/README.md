# Low-Level Design (LLD) Using Core Java

A collection of practical Low-Level Design (LLD) projects implemented using Core Java.

This repository demonstrates object-oriented programming, data structures, problem-solving, and the application of software design principles through real-world scenarios.

## Technology Stack

- Java 21
- Core Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Data Structures and Algorithms

## Projects

### Banking & Finance

| Project | Description | Concepts |
|---|---|---|
| ATM Cash Management System | Simulates ATM deposits, withdrawals, and cash inventory management. | OOP, Collections, Cash Denominations |
| Bank Token Queue Management System | Manages customer tokens, service-specific queues, and banking counters. | Queue, HashMap, ArrayList, FIFO |

## Running the Projects

These are standalone Java applications. Maven and Gradle are not required unless explicitly mentioned in an individual project.

Prerequisites:
- JDK 21 or later
- Java IDE or command-line terminal

Each project contains its own source code and README with compilation and execution instructions.

## Design Principles

The projects focus on:

- Object-oriented design
- Separation of responsibilities
- Encapsulation
- Appropriate data structure selection
- Readable and maintainable code
- Practical business use cases
